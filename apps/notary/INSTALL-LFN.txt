PANTHERA WORKS 1.0 — LONG FILE NAME SUPPORT

DOCX, XLSX and PPTX use long filenames. DOS environments without native LFN support need an external DOS LFN
driver for these formats. This application folder does not include DOSLFN or
CP437UNI.TBL. Obtain and install the driver independently, and follow the
driver package's own instructions and license terms.

The driver must be available as the DOS command DOSLFN, and CP437UNI.TBL must
be placed where that driver expects it. Run this application from a writable,
LFN-capable drive. The CD-ROM itself is not a writable work drive.

Keep LFNCHK.EXE beside NOTARY.BAT and NOTARY.EXE. Start Notary with NOTARY.BAT;
the launcher loads/checks the driver and starts NOTARY.EXE only when the LFN
API is available. If the check fails, review the driver's installation and
the LFNCHK output before retrying.

DOSLFN and CP437UNI.TBL are not Panthera Works components and are not included
or redistributed with this application.
